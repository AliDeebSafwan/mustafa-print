# الوثائق

كل ملف هنا له غرض واحد. ابدأ بالخطة.

| أين | ما فيه | لمن |
|---|---|---|
| `ROADMAP.md` | الخطة كاملة: ما أُنجز، ما بقي، القرارات المطلوبة منك، والمخاطر | المالك |
| `training/` | دليل الموظف ودليل المدير وورقتان سريعتان (Markdown وPDF) لتطبيق الموظفين | الموظفون والمالك |
| `website-guide/` | دليل موقع الزبائن صفحةً صفحة بالصور (PDF) | المالك |
| `design/` | قرارات تصميم الموقع وقواعده، ومقارنات قبل وبعد | من يعدّل شكل الموقع |
| `reports/` | تدقيق الأمان وقياسات السرعة، بالأرقام وطريقة القياس | المالك والمطوّر |
| `database/` | تصميم قاعدة البيانات وأسبابه، ومخطط الجداول، وقاموس كل عمود | المطوّر |

## ملاحظات

- **`database/erd.mermaid` و`database/DATA-DICTIONARY.md` مولَّدان آلياً** من قاعدة البيانات بالأمر `pnpm db:erd`. لا تعدّلهما يدوياً.
- **مجلدات `tools/`** داخل `training` و`design` و`website-guide` فيها أدوات إعادة توليد الصور والـPDF. طريقة الاستعمال في ملف `README.md` لكل منها.
