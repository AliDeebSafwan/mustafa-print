# دليل الموقع (PDF)

`website-guide.pdf`: كل صفحات موقع الزبائن بالصور، مع شرح ما يراه الزبون وما يفعله ومن أين يُعدَّل المحتوى. النص في `guide.md`، والصور في `img/`.

## إعادة توليده

لنسخة محلية فقط، بعد أي تغيير في شكل الموقع:

1. **تشغيل متجر تجريبي**، من `docs/design/tools`:
   - `./demo-up.sh`
   - `python3 seed_flows.py http://127.0.0.1:4280 owner@demo.example demo-owner-password-long /tmp/demo-img` (يطبع رموز طلب وعرض سعر وبروفة)
   - `./web-up.sh`
2. **تصوير الصفحات**، من `tools` هنا:
   ```
   node capture.mjs http://localhost:3380 ../img ORDER QUOTE PROOF /tmp/design-api.log FILE.pdf
   ```
   يتصفّح الموقع كزبون: ينشئ حساباً، ويؤكّد البريد من سجل الخادم التجريبي، ويشتري، ويجد طلبه. أي خطوة فشلت تُطبع بكلمة `FAIL`.
3. **بناء الـPDF:** `node build-pdf.mjs`
4. **إيقاف المتجر التجريبي:** `../../design/tools/demo-down.sh`

المكتبات: `npm install` هنا، أو ربط `node_modules` بمجلد `docs/training/tools` الذي فيه المكتبات نفسها.

## ما يجب معرفته

- **المحتوى في الصور تجريبي:** أسماء وخدمات ورسومات بديلة، لا بيانات حقيقية.
- **صفحة السلة فيها اهتزاز صغير (0.043) عند فتحها**، لأن محتواها يُقرأ من الهاتف بعد ظهور الصفحة. ضمن حد «جيد» (أقل من 0.1)، لكنه ليس صفراً كباقي الصفحات.
