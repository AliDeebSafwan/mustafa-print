# ورقة الموظف السريعة

## طلب جديد
1. **الطلبات ← طلب جديد**
2. **العميل**: ابحث بالاسم أو الهاتف، أو **عميل جديد**
3. **إضافة من قائمة المنتجات** أو **إضافة بند يدوي** ← الكمية
4. **استلام من المطبعة** أو **توصيل** ← **حفظ الطلب**

## تقدّم الطلب
افتح الطلب ← **نقل الطلب إلى** ← المرحلة التالية، عند الانتقال إليها فعلاً.

## الدفع
الطلب ← **المدفوعات** ← عدّل **المبلغ** إن كان جزئياً ← **تسجيل الدفعة**

## الملصق
الطلب ← **طباعة ملصق الطلب** ← الصقه على العمل

## البحث عن طلب
**مسح** ← الكاميرا على الملصق، أو اكتب الرمز ← **بحث**

## البروفة
الطلب ← **إرسال بروفة للزبون** ← ارفع الملف ← أرسل الرابط بواتساب

## بدون إنترنت؟
**تابع العمل.** كل شيء يُحفظ ويُرسل وحده عند عودة الاتصال.
**لا تمسح بيانات المتصفح** ما دام في **الإعدادات ← تغييرات لم تُرسل** رقم أكبر من 0.

## يحتاج المدير
الإلغاء · الاسترداد · خصم فوق السقف · تعديل طلب بدأت طباعته أو دُفع منه · تغيير أسعار المنتجات
