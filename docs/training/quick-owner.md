# ورقة المدير اليومية

| متى | أين |
|---|---|
| صباحاً | **التقارير ← طابور الإنتاج**: ما يجب إنجازه، المتأخر أولاً |
| طوال اليوم | تنبيه طلبات الموقع (فعّله من **الإعدادات**) |
| آخر النهار | **التقارير ← إغلاق الصندوق**: طابق النقد مع الدرج |
| أسبوعياً | **التقارير ← الذمم**: تواصل مع من لم يسدد |

## مرة واحدة عند البدء
1. **الموقع ← بيانات المحل**: العنوان، البريد، الهاتف، واتساب، ساعات العمل
2. **الإعدادات ← الطاقم ← الإعدادات**: الاسم القانوني، الرقم الضريبي، سقف الخصم، العربون
3. **الطاقم ← إضافة عضو**: حساب لكل موظف
4. **المنتجات ← منتج جديد**: قائمة الأسعار

## عند فقدان هاتف موظف
**الطاقم** ← الموظف ← **إنهاء الجلسات على كل الأجهزة** ← ثم **إعادة تعيين كلمة السر**

## قرارات تبقى لك وحدك
الإلغاء · الاسترداد · تجاوز الخصم والعربون والحد الائتماني · الأسعار · أجرة التوصيل · الحسابات على الموقع (تعطيل ودمج)

## كل ما يحدث مسجَّل
**الطاقم ← سجل التدقيق**: من فعل ماذا ومتى. لا يُعدَّل ولا يُحذف.
